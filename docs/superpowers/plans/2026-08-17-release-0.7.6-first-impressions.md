### Task 2: #37 — wake-up nudge counts in watermark units

**Files:**
- Modify: `hooks/wake-up/wakeup/__init__.py` (`_unlinted_count`, ~:870-905)
- Test: `tests/hooks/` — find the existing `_unlinted_count`/nudge tests (`grep -rln unlinted tests/hooks/`) and extend.

**Interfaces:**
- Consumes: the two on-disk contracts — `state_dir()/journal.jsonl` (one JSON object per line) and `state_dir()/wiki_lint_watermark.json` (`{"journal_lines_seen": int, ...}`).
- Produces: no API change. `_unlinted_count` now counts EXACTLY the lines `lib.memory.journal.entries()` would return, because the watermark is stamped in those units (`skills/wiki-health/lib/lint.py:446`: `total_journal_lines = len(journal.entries())`).

Root cause (verified): `journal.entries()` skips blank lines AND lines that fail `json.loads` AND parsed non-dict lines (lib/memory/journal.py:47-75); the watermark seed is `len(journal.entries())`. Wake-up's `_unlinted_count` counts every non-blank raw line — so any malformed or non-object journal line makes the nudge and the watermark disagree forever. The fix keeps the hook stdlib-only: replicate the skip rules with `json.loads` per line, not an import of `lib.memory.journal`.

- [ ] **Step 1: Write the failing test**

```python

    journal_path.write_text(
        '{"page": "a.md", "op": "ADD"}\n'
        'not json at all\n'
        '{"page": "b.md", "op": "ADD"}\n'
        '"just a string"\n'
        '\n'
        '{"page": "c.md", "op": "ADD"}\n',
        encoding="utf-8",
    )
    # Watermark stamped at 2 entries-units: exactly 1 valid entry is unlinted.
    (<state_dir> / "wiki_lint_watermark.json").write_text(
        '{"journal_lines_seen": 2, "clean": true, "stamped_at": "2026-08-17T00:00:00+00:00"}',
        encoding="utf-8",
    )
    assert _unlinted_count() == 1
```

- [ ] **Step 3: Implement**

In `_unlinted_count`, replace the raw non-blank count with entries-unit counting (stdlib only — `json` is already imported in the hook):

```python
            lines = 0
            for line in handle:
                if not line.strip():
                    continue
                # Count in the SAME units the watermark is stamped in:
                # len(journal.entries()), which skips malformed and
                # non-object lines (lib/memory/journal.py). A raw non-blank
                # count drifts one nudge unit per bad line, forever (#37).
                try:

                        lines += 1

                    continue
```

  1. The identical-content noop-duplicate check ALSO compares against existing `<slug>-N.md` siblings — content identical to any sibling → noop-duplicate instead of landing a duplicate `-N+1` page (#66 item 1).
  2. `_free_suffix_page` guards the `.md` assumption: for a page not ending `.md`, suffix before the final extension is not attempted — split on the last `.` only when the suffix is `.md`, else append `-N` before a trailing `.md` is NOT assumed; simplest correct rule: `stem, sep, ext = page.rpartition(".md")` guard — implement as: if not `page.endswith(".md")`, uniquify as `f"{page}-{n}"` (whole-name suffix) (#66 item 2).
