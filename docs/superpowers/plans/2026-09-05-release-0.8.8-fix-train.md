### Task 1: Backup — `git init` a fresh wiki instead of refusing

**Why.** `/ren:install`'s wiki stamping never runs `git init`. `setup_remote` then refuses a non-repo wiki with "Run /ren:install to bootstrap", which cannot help, and `backup()` refuses the same way. Once the wiki has content, `lib.governance.backup_gate.require_backup` blocks a second `/ren:ingest-project`, so a friend who declined backup at install is stuck (confirmed on the 2026-09-05 Windows smoke; worked around by a manual `git init`).

**Fix.** One helper, `ensure_git_repo(wiki_root) -> bool`, that returns True if the directory is already a repo, otherwise runs `git init` there and returns whether that succeeded. Both `setup_remote` and `backup()` call it first; the `not-a-git-repo` refusal becomes a `git-init-failed` refusal that fires only when `git init` itself fails (e.g. the path is not a directory).

### Task 3: Metric-watch — fan-out-silent fires once per window, not every run

**Why.** `_check_fanout_silent(state)` receives the persisted `state` dict and ignores it. Its three siblings (`_check_classifier_fail_closed`, `_check_no_llm_with_candidates`, `_check_memory_growth`) all keep a since-last-watch watermark in `state`, so a finding is raised once. Fan-out-silent re-reports the same seven-day window on every run until the window ages out.

**Fix.** Same watermark pattern as `_check_classifier_fail_closed`: remember the newest `fanout_event` ts seen; only fire when there is at least one event newer than the watermark and every event in the window has zero candidates.

```python
        e for e in collect.read(kind=collect.KIND_FANOUT_EVENT)

    # Without it the same silent window re-fires on every run until it ages

    last_ts = state.get("last_fanout_ts")

    state["last_fanout_ts"] = max(e.get("ts", "") for e in recent)

    if not new_events:
        return None
    if any(e.get("candidates", 0) > 0 for e in recent):
        return None
    return {"kind": "fan-out-silent", "count": len(recent), "days": FANOUT_SILENT_DAYS}
```

### Task 5: Lint — the asymmetric-link fix skips ambiguous basenames

**Why.** Wikilinks resolve by basename. The sweep's `_asymmetric_links` (`skills/wiki-health/lib/__init__.py:840`) already skips a `[[stem]]` that resolves to zero or more than one page. The lint's write-side helper `_missing_reverse_stems` (`skills/wiki-health/lib/lint.py:386`) does not: it matches `Path(page).stem` against every `## Related` list with no uniqueness check, so when two pages share a basename, both receive the reverse bullet and one of them is wrong. A wrong `## Related` bullet is then itself an asymmetric link, so the error propagates on the next sweep.

**Fix.** In `_missing_reverse_stems`, build the same `by_stem` map the sweep uses and skip when the page's own stem is not unique in the index, and skip a source whose stem is not unique either (its reverse bullet `[[src-stem]]` would not resolve unambiguously).

```python
def _missing_reverse_stems(page: str, index: LinkIndex) -> list[tuple[str, str]]:
    """`(stem, reason)` for every page that lists `page` under `## Related`
    while `page` does not list it back.

    Wikilinks resolve by basename, so a reverse bullet is only safe when
    BOTH stems are unique in the index: if `page`'s stem is shared, the
    forward `[[stem]]` may have meant the other page; if the source's stem
    is shared, the reverse `[[src-stem]]` would not resolve. Same rule the
    sweep's `_asymmetric_links` applies (0.8.7 review ledger)."""
    by_stem: dict[str, int] = {}
    for rel in index.pages:
        s = Path(rel).stem
        by_stem[s] = by_stem.get(s, 0) + 1

    page_stem = Path(page).stem
    if by_stem.get(page_stem, 0) != 1:
        return []

    own = {s for s, _ in index.related.get(page, [])}
    out: list[tuple[str, str]] = []
    for src, related in index.related.items():
        if src == page:
            continue
        src_stem = Path(src).stem
        if by_stem.get(src_stem, 0) != 1:
            continue
        if any(s == page_stem for s, _ in related) and src_stem not in own:
            out.append((src_stem, ""))
    return sorted(set(out))
```
