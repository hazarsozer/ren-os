## 2. #62 — Live-pins filter + spine-page delete guard

**Files:** `skills/wrap/lib/__init__.py` (`live_pin_pages`, ~:1494-1531),
`skills/pin/lib/` (`correct`), `skills/wrap/SKILL.md` (delete protocol, ~:99)

Two independent layers:

(a) **Listing filter:** `live_pin_pages()` additionally skips entries
whose proposal op is `UPDATE`. Rationale: a pin UPDATE is a restoration
or correction of an existing page, not a note with a lifecycle — it has
no "keep / expand / delete" decision to offer. The two #58 restoration
writes (`q-01KZXD2H37WW05W73QZ8RRFSM9` → log.md,
`q-01KZXD2H2VM0KF1218EQ78K4YA` → identity.md) stop rendering.

(b) **Hard guard:** `skills.pin.lib.correct()` refuses `content=None`
(delete) when the target page is a spine page — `log.md`, `identity.md`,
`index.md`, or any path ending in `map.md` — **regardless of
`approved_by`**. The refusal error names the #58 incident so the
operator understands why. `approved_by` continues to force through
instruction-plane holds for non-spine pages exactly as today.

(c) **Protocol note:** the SKILL.md delete step documents that spine
pages are refused by the library.

**Tests:** restoration UPDATE entries absent from `live_pin_pages()`
output while ADD pins still list; `correct("log.md", None, ...,
approved_by=...)` raises/returns refusal; ordinary task-pin delete on a
non-spine page still works; each of the four spine shapes refused.

## 3. #50 — calibration floor symmetry

**Files:** `lib/instrument/estimator.py` (`_load_ratio_state`, ~:53-69),
`hooks/wake-up/wakeup/__init__.py` (`_calibrated_chars_per_token`, ~:208-256)

`estimator.py` becomes the single home of the calibration acceptance
rules: `MIN_CALIBRATION_SAMPLES = 5` and the plausibility band (same
band wake-up uses today). `_load_ratio_state` rejects ratios with
`samples < MIN_CALIBRATION_SAMPLES` or outside the band, falling back to
the default ratio. Wake-up references the same values — by import if the
hook's path setup allows, otherwise mirrored constants with a
cross-reference comment naming `estimator.py` (decided at
implementation; whichever the hook environment supports). The stale
wake-up docstring (~:220) claiming estimator already carries the band is
corrected either way.

**Tests:** 1-sample ratio → default; 4-sample → default; 5-sample
in-band → honored; out-of-band ratio at any sample count → default;
`skills/code-map` consumer path unaffected (existing tests stay green).

## 4. #38 — wiki-health heuristic precision

**File:** `lib/memory/semantics.py` (`contradiction_evidence` ~:236-250,
`_detect_contradictions` ~:198-232, `numeric_drift_evidence` ~:275-311)

**Contradiction pass:** two new skips before pairing —
(1) line pairs identical after `_normalize_line` (agreement is never
contradiction); (2) pointer/log-line shapes: any line
`lib.pointer.parse_pointer_line` recognizes (link or arrow form) is
excluded from the contradiction candidate set — pointer lines state
locations, not claims.

**Numeric drift:** scope the all-pairs template comparison with the
existing `semantics.project_subtree` helper — a drift pair is only
reported when both pages belong to the same project subtree (pages
outside any project subtree compare only among themselves). Different
projects' ingest dates stop colliding. The
`_MIN_SIGNIFICANT_TOKENS_TO_CONSIDER` gate stays.

**Tests:** reproduce both live false positives from the issue verbatim
(the index.md ↔ ren-os map decision-map line; the genshin ↔ ren-os
ingest dates) and assert neither fires; keep at least one true positive
of each heuristic green (real negation contradiction; same-project
numeric drift).

## 5. #68 — generated guard-test tier

**File:** new `tests/hooks/test_guards_generated.py`

A deterministic generated corpus via `itertools` — no `hypothesis`
dependency (deps stay minimal, CI stays deterministic):

- **Axes:** guarded verb+flag shapes (from the guard matrix) × innocuous
  prefix commands × separators (`&&`, `;`, `|`, newline) × quoting/
  escaping variants (bare, single-quoted segment, double-quoted segment,
  flag split by `=` where applicable).
- **Oracle:** any segment containing a guarded verb+flag ⇒ block; a
  command composed only of innocuous segments ⇒ allow.
- Assert the real guard's verdict equals the oracle for every generated
  command. Cap the product to a bounded, enumerable size (target:
  low thousands of cases, sub-second).

The 94 hand-written cases in `tests/hooks/test_guards.py` remain as
regression anchors. Note: generated secret-shaped or force-push-shaped
strings must be assembled at runtime (existing repo convention) so the
repo's own pre-push scan does not block the train's release.
